# Game System Designer Skill

A portable Codex skill for source-disciplined game-system planning. It connects player-facing rules, interaction flows, UI states, project configuration, and acceptance criteria while preventing unconfirmed assumptions from becoming formal design.

- [中文使用须知](docs/USAGE.zh-CN.md)
- [English Usage Guide](docs/USAGE.en.md)

The skill does not include any project's proprietary configuration, UI, art, or planning templates. Each project supplies its own material library on first use.
