# Game System Designer Skill

A portable Agent Skill for source-disciplined game-system planning. It connects player-facing rules, interaction flows, UI states, project configuration, editable deliverables, and acceptance criteria while preventing unconfirmed assumptions from becoming formal design.

- [中文使用须知](docs/USAGE.zh-CN.md)
- [多 AI 客户端兼容与安装须知](docs/AI-COMPATIBILITY.zh-CN.md)
- [English Usage Guide](docs/USAGE.en.md)
- [Multi-agent compatibility and setup](docs/AI-COMPATIBILITY.en.md)

The core bundle follows the `SKILL.md` Agent Skills format. It can be used by Codex, DeepSeek Harness, Claude Code, Gemini CLI, Cursor, GitHub Copilot, and other compatible agents, but installation paths, invocation syntax, and available tools differ by host.

The repository does not include any project's proprietary configuration, UI, art, planning templates, credentials, or private paths. Each project supplies its own material library on first use.
